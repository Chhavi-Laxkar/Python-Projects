# 🧮 Calculator

A simple command-line Calculator application built using Python. It allows users to perform basic as well as some advanced mathematical operations.

## ✨ Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Square Root
- Floor Division
- Percentage
- Average

## 📋 Requirements

- Python 3.x

## 🚀 How to Run

1. Open the project folder.
2. Run the following command:

```bash
python calculator.py
```
