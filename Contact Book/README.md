# 📱 Contact Book

A simple **Contact Book application built using Python**.
This project is designed for beginners to practice basic Python concepts such as dictionaries, loops, conditional statements, user input, and menu-driven programs.

## 🚀 Features

* ➕ Add a new contact
* 👀 View all contacts
* 🔍 Search for a contact
* 🗑️ Delete a contact
* 🚪 Exit the application
* ❌ Handles invalid menu choices

## 🛠️ Technologies Used

* Python 3
* Dictionaries
* While Loop
* For Loop
* If-Else Conditions
* User Input
