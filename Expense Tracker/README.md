# 💰 Expense Tracker

A simple **Expense Tracker application built using Python**.

This project allows users to add, view, calculate, and delete their expenses through a simple menu-driven program.

It is a beginner-friendly Python project created to practice basic programming concepts.

---

## 🚀 Features

- ➕ Add Expense
- 👀 View All Expenses
- 💰 Calculate Total Expenses
- 🗑️ Delete an Expense
- 🚪 Exit the program
- ❌ Handles invalid menu choices

---

## 🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- `while` loop
- `for` loop
- `if-elif-else`
- User Input
- `enumerate()`
