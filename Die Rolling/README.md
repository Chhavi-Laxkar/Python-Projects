# 🎲 Dice Rolling Game

A simple Python Dice Rolling Game that generates two random dice values every time the user chooses to roll.

## Features

- Rolls two dice simultaneously
- Random numbers between 1 and 6
- User can continue rolling
- Exit anytime by entering `n`

## Requirements

- Python 3.x

## How to Run

```bash
python die_game.py
```

## Example Output

```
Roll a Die (y/n): y
(3, 6)

Roll a Die (y/n): y
(1, 5)

Roll a Die (y/n): n
Thanks for playing!
```
